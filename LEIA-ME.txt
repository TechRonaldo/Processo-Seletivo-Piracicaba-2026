Para o modo PWA/offline funcionar completamente, abra o app por HTTP/HTTPS (service workers não funcionam em file://).
Exemplo local, se houver Python instalado:
1. Abra um terminal nesta pasta.
2. Execute: python -m http.server 8080
3. Abra no navegador: http://localhost:8080
4. Depois do primeiro carregamento, o app fica disponível offline pelo cache.

O CPF é opcional, recebe máscara 000.000.000-00, é validado apenas no navegador e não é salvo.
Os sons são sintetizados pelo Web Audio API; não usam arquivos ou sons de terceiros.
